# Deep Dive Completeness Checklist

Grade a deep dive here before calling it finished. Three gates: **Gate 0** (the five quality
layers — research vs deck), **Gate 1** (the must-have modules), **Gate 2** (craft).

Keep the layers *here*, on one page — don't sprinkle them through the write-up. During
writing it should feel like a **research flow**; here is where it gets graded like a checklist.

---

## GATE 0 — The Five Mandatory Layers (research vs deck)
- [ ] **A — Facts:** every material claim = **number + date + source**. No undated "is rising."
- [ ] **B — Economics:** profit pools + **who captures them** + **margin-migration direction**;
      companies judged on **returns on capital**.
- [ ] **C — Cycles:** **cycle position + a Cycle Dashboard of leading indicators**, with the
      **demand cycle separated from the stock cycle** where they diverge.
- [ ] **D — Failure Modes:** a **Graveyard** (who died + why + base rate) AND a **Live Risk
      Dashboard** (today's thesis-killers + tripwires).
- [ ] **E — Scorecards:** a **weighted, 1–5, rankable** rubric + a **Capital Allocation score**,
      with **≥1 company scored end-to-end**.

**Any layer unchecked → it's "educational," not "investment research." Fix before publishing.**

---

## GATE 1 — Must-have modules (the minimum bar)
- [ ] **Research Question** stated up front — the central uncertainty + what would prove/disprove it
- [ ] **Archetype tagged** (Commodity / Technology / Regulated / Infrastructure / Hybrid)
- [ ] **Why now** — 3+ dated reasons
- [ ] **Plain-English definition** (5-year-old test)
- [ ] **How it's made** — process/pipeline + cost stack
- [ ] **Segments** broken out, each with a **tell metric**
- [ ] **Value-chain margin map** — pools + who captures them + migration direction
- [ ] **Industry structure** — concentration + barriers to entry
- [ ] **Cycle Dashboard** — leading indicators table (current / 5Y avg / direction)
- [ ] **Management & Capital Allocation** module with a score
- [ ] **Evaluation scorecard** (weighted) defined *before* company analysis
- [ ] **2–3 company deep dives** with Balance Sheet + P&L + **ROCE/ROE**, ranked by the rubric
- [ ] **Historical Graveyard** (how value dies here)
- [ ] **Live Risk Dashboard** (thesis-killers + tripwires)
- [ ] **Consensus vs Variant View** (what consensus believes; where you differ; evidence)
- [ ] **Valuation** with a sector-appropriate method + margin-of-safety check
- [ ] **Investment Fit** (compounder / cyclical / turnaround / special-sit — at what price/cycle)
- [ ] **Conclusion** that answers the Research Question (your own view)
- [ ] **Data sources / monitoring cadence** appendix

## GATE 2 — Craft (good → great)
- [ ] **Facts > opinions** — claims sourced, not vibes
- [ ] **Altitude shifts** — macro (why now) ↔ mid (structure/value chain) ↔ ground (companies)
- [ ] **Comparable company layouts** — same template for every company
- [ ] **Self-researchable** — a reader could update it from the sources listed
- [ ] **Visual where it counts** — value chain, timeline, Porter's, both dashboards as tables/diagrams
- [ ] **Archetype weighting respected** — ~60% effort on the over-weighted modules, full coverage elsewhere
- [ ] **Contrarian edge** — the variant view is genuinely non-consensus and evidenced, not a strawman

---

## Generic data-source starter list
Adapt per industry; default kit observed across the decks.

**Primary / company-level:** annual reports, investor decks, earnings transcripts,
exchange filings & corporate announcements (BSE/NSE; SEC for US), capacity/order-book disclosures.

**Industry / macro:** sector regulator & ministry sites, policy docs (PLI, duties, NITI Aayog),
industry associations/councils, IEA, BloombergNEF, McKinsey/BCG/Bain, Goldman/BlackRock/Nomura,
specialist creators (YouTube/X/Substack), trade press (Bloomberg, CNBC, Quartz).

**Monitoring cadence:** define the 3–5 **tell metrics** for *this* industry (the Cycle Dashboard),
how often to refresh them, and from where. That dashboard is your living version of the deep dive.
