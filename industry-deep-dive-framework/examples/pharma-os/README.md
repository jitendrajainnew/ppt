# Pharma OS — the Operating System, not the Report

> **The core idea (from the workflow):** `pharma.md` is **not the final product** — it's the
> *operating system* from which live research, dashboards, company rankings, and investment
> theses are generated. This folder is what the OS *produces*.

```
  Framework  →  pharma.md (the encyclopedia / master map)  →  THIS FOLDER:
                                                              ├── DASHBOARD.md        (live KPIs)
                                                              ├── COMPANY-SCORECARDS.md (scored, ranked)
                                                              ├── QUESTION-BANK.md     (unanswered Qs = where alpha is)
                                                              └── INVESTMENT-MEMO.md   (1-page IC + variant views)
```

The 7-stage workflow:
**Fill pharma.md (30%) → Research database (40%) → Question Bank → Dashboard → Company Scoring →
Variant Views → Investment Memo.** The memo is the *last* 5% — but it's the part that makes money.

## What's in this folder

| Asset | What it is | Refresh cadence |
|---|---|---|
| [`DASHBOARD.md`](DASHBOARD.md) | The live KPI scoreboard — current values + source + date | Monthly |
| [`COMPANY-SCORECARDS.md`](COMPANY-SCORECARDS.md) | 6 companies scored on one rubric, ranked, with evidence | Quarterly |
| [`QUESTION-BANK.md`](QUESTION-BANK.md) | The unanswered question per module — research is Q→Evidence→Answer | Ongoing |
| [`INVESTMENT-MEMO.md`](INVESTMENT-MEMO.md) | 1-page IC summary + the **variant views** (the alpha) | On thesis change |
